# Welcome - 欢迎页模块

> **Workspace 模块** | 路径: `feature/welcome`

## 📦 模块概述

Welcome 模块提供应用启动时的欢迎界面和引导页功能，包括启动屏、应用介绍、引导教程等，为用户提供良好的首次使用体验。

## ✨ 主要功能

### 🎯 启动欢迎页
- **启动屏** - 应用启动时的品牌展示
- **初始化加载** - 应用数据初始化过程展示
- **平滑过渡** - 优雅的页面过渡动画

### 📖 引导页
- **功能介绍** - 应用主要功能介绍
- **使用指南** - 新用户使用引导
- **轮播展示** - 多页引导内容轮播

### ⚙️ 初始化检查
- **版本检查** - 应用版本更新检查
- **权限申请** - 必要权限预申请
- **首次启动** - 首次启动标记和处理

## 🔗 依赖关系

**依赖的 workspace 模块：**
- `bizapi` - 业务 API 接口

## 🚀 使用方式

在根目录 `pubspec.yaml` 中已配置为 workspace 成员，其他模块可直接引用：

```yaml
dependencies:
  welcome:  # 自动使用 workspace 版本
```

## 📝 开发命令

```bash
# 进入模块目录
cd feature/welcome

# 获取依赖
flutter pub get

# 生成国际化文件
flutter gen-l10n
```

**或使用项目根目录的批量脚本：**

```bash
./scripts/pub_get_all.sh       # 所有模块获取依赖
./scripts/gen_l10n_all.sh      # 所有模块国际化生成
```

1. **应用首次启动** - 显示引导页
