# User - 用户管理模块

> **Workspace 模块** | 路径: `business/user`

## 📦 模块概述

User 模块是应用的用户管理核心模块，提供用户信息管理、部门管理、岗位管理、角色管理等功能，包括用户个人中心、个人资料编辑、密码修改、头像上传等个人信息管理功能。

## ✨ 主要功能

### 👤 用户管理
- **用户列表** - 用户信息查看和管理
- **用户新增** - 创建新用户
- **用户编辑** - 修改用户信息
- **用户删除** - 删除用户
- **用户导入** - 批量导入用户
- **用户导出** - 导出用户数据
- **重置密码** - 管理员重置用户密码

### 🏢 部门管理
- **部门树** - 树形展示组织架构
- **部门新增** - 创建新部门
- **部门编辑** - 修改部门信息
- **部门删除** - 删除部门
- **部门排序** - 调整部门顺序

### 💼 岗位管理
- **岗位列表** - 岗位信息查看
- **岗位新增** - 创建新岗位
- **岗位编辑** - 修改岗位信息
- **岗位删除** - 删除岗位
- **岗位分配** - 用户岗位分配

### 🎭 角色管理
- **角色列表** - 角色信息查看
- **角色新增** - 创建新角色
- **角色编辑** - 修改角色信息
- **角色删除** - 删除角色
- **权限分配** - 角色菜单权限配置
- **数据权限** - 角色数据范围权限配置

### 👨‍💼 个人中心
- **个人信息** - 查看个人基本信息
- **个人资料** - 编辑个人资料
- **修改密码** - 修改登录密码
- **头像上传** - 上传和裁剪头像
- **安全设置** - 账户安全相关设置

### 🔐 权限管理
- **用户角色** - 用户角色分配
- **角色权限** - 角色菜单权限
- **数据权限** - 按部门/个人的数据权限
- **权限验证** - 按钮级权限验证

## 🔗 依赖关系

**依赖的 workspace 模块：**
- `fast` - 快速开发工具
- `db_base` - 数据持久化
- `bizapi` - 业务 API 接口

**主要第三方依赖：**
- `provider` - 状态管理
- `image_picker` - 图片选择
- `crop_your_image` - 图片裁剪

## 🚀 使用方式

在根目录 `pubspec.yaml` 中已配置为 workspace 成员，其他模块可直接引用：

```yaml
dependencies:
  user:  # 自动使用 workspace 版本
```

## 📝 开发命令

```bash
# 进入模块目录
cd business/user

# 获取依赖
flutter pub get

# 生成代码（JsonSerializable 等）
dart run build_runner build --delete-conflicting-outputs

# 生成国际化文件
flutter gen-l10n
```

**或使用项目根目录的批量脚本：**

```bash
./scripts/pub_get_all.sh       # 所有模块获取依赖
./scripts/build_runner_all.sh  # 所有模块代码生成
./scripts/gen_l10n_all.sh      # 所有模块国际化生成
```

## 💡 模块特点

1. **完整的用户体系** - 用户、部门、岗位、角色完整管理
2. **灵活的权限控制** - 菜单权限和数据权限分离
3. **友好的用户体验** - 直观的组织架构树形展示
4. **个人中心** - 完善的个人信息管理
5. **批量操作** - 支持用户批量导入导出
