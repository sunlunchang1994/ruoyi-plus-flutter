# System - 系统管理模块

> **Workspace 模块** | 路径: `business/system`

## 📦 模块概述

System 模块是应用的系统管理核心模块，提供完整的后台管理功能，包括租户管理、用户管理、角色权限、菜单管理、字典管理、参数配置、日志监控、文件管理等功能，对应 RuoYi-Vue-Plus 系统管理模块。

## ✨ 主要功能

### 🏢 租户管理
- **租户列表** - 查看、新增、编辑、删除租户
- **租户套餐** - 租户套餐配置和管理
- **租户信息** - 企业信息、过期时间、用户数量限制
- **套餐菜单** - 配置套餐包含的菜单权限

### 📋 字典管理
- **字典类型** - 字典分类管理
- **字典数据** - 字典数据维护
- **字典缓存** - 字典数据本地缓存
- **多选支持** - 字典数据多选对话框

### 📂 菜单管理
- **菜单列表** - 菜单树形展示
- **菜单编辑** - 新增、修改、删除菜单
- **权限配置** - 按钮权限、数据权限配置
- **菜单选择** - 单选、多选菜单组件

### ⚙️ 参数管理
- **参数配置** - 系统参数的配置和管理
- **参数查询** - 参数列表查看和搜索
- **参数编辑** - 新增、修改、删除参数

### 📢 通知公告
- **公告列表** - 系统公告查看
- **公告管理** - 新增、编辑、删除公告
- **公告发布** - 公告发布和撤回

### 📝 日志管理
- **操作日志** - 用户操作日志记录和查询
- **登录日志** - 用户登录记录和查询
- **日志详情** - 日志详细信息查看
- **日志统计** - 日志数据统计分析

### 📁 文件管理
- **文件列表** - OSS 文件展示和管理
- **文件上传** - 文件上传功能
- **文件下载** - 文件下载和预览
- **文件删除** - 文件删除管理
- **存储配置** - OSS 配置管理（多种存储方式）

### 👥 在线用户
- **在线用户列表** - 当前在线用户查看
- **强制下线** - 踢出在线用户
- **会话管理** - 用户会话管理

### 📊 缓存监控
- **缓存信息** - Redis 缓存信息查看
- **缓存统计** - 缓存命中率、内存使用等统计
- **缓存管理** - 缓存清理和管理

### 🔌 客户端管理
- **客户端列表** - OAuth2 客户端管理
- **客户端配置** - 客户端密钥、权限配置
- **授权管理** - 客户端授权范围管理

### 🎨 路由导航
- **功能菜单** - 系统功能模块网格展示
- **快捷入口** - 常用功能快速访问

### ⚙️ 设置中心
- **系统设置** - 应用系统设置
- **关于应用** - 应用版本、开源协议等信息

## 🔗 依赖关系

**依赖的 workspace 模块：**
- `fast` - 快速开发工具
- `db_base` - 数据持久化
- `base` - 基础核心模块

## 🚀 使用方式

在根目录 `pubspec.yaml` 中已配置为 workspace 成员，其他模块可直接引用：

```yaml
dependencies:
  system:  # 自动使用 workspace 版本
```

## 📝 开发命令

```bash
# 进入模块目录
cd business/system

# 获取依赖
flutter pub get

# 生成代码（JsonSerializable 等）
dart run build_runner build --delete-conflicting-outputs

# 生成国际化文件
flutter gen-l10n
```

**或使用项目根目录的批量脚本：**

```bash
./scripts/pub_get_all.sh       # 所有模块获取依赖
./scripts/build_runner_all.sh  # 所有模块代码生成
./scripts/gen_l10n_all.sh      # 所有模块国际化生成
```
