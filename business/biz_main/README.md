# BizMain - 主业务模块

> **Workspace 模块** | 路径: `business/biz_main`

## 📦 模块概述

BizMain 模块是应用的主业务入口模块，负责整合系统管理、用户管理等各个业务模块，提供应用的主界面框架、导航结构和核心业务流程。

## ✨ 主要功能

### 🏠 主界面框架
- **底部导航栏** - 主要功能模块的底部导航
- **侧边抽屉** - 用户信息和系统菜单
- **首页仪表盘** - 数据概览和快捷入口

### 📊 数据可视化
- **统计图表** - 基于 `fl_chart` 的数据可视化
- **数据大屏** - 关键业务指标展示
- **实时监控** - 系统运行状态监控

### 🎯 业务集成
- **系统管理集成** - 集成系统管理模块功能
- **用户管理集成** - 集成用户管理模块功能
- **工作流集成** - 工作流和审批流程（规划中）

### 🔔 消息通知
- **通知中心** - 系统通知和消息管理
- **待办事项** - 待处理任务提醒
- **消息推送** - 实时消息推送

### 📱 应用设置
- **主题切换** - 明暗主题切换
- **语言切换** - 多语言切换
- **系统设置** - 应用配置和偏好设置

## 🔗 依赖关系

**依赖的 workspace 模块：**
- `fast` - 快速开发工具
- `db_base` - 数据持久化
- `bizapi` - 业务 API 接口

**主要第三方依赖：**
- `fl_chart` - 数据图表
- `provider` - 状态管理

```
biz_main/
```

## 🔄 与其他模块的关系

```
biz_main (本模块)
 ├─ 被依赖: 主应用
 ├─ 依赖: fast, db_base, bizapi, system, user
 └─ 作用: 整合所有业务模块，提供统一的应用入口
```

## 🚀 使用方式

在根目录 `pubspec.yaml` 中已配置为 workspace 成员，主应用直接引用：

```yaml
dependencies:
  biz_main:  # 自动使用 workspace 版本
```

## 📝 开发命令

```bash
# 进入模块目录
cd business/biz_main

# 获取依赖
flutter pub get

# 生成国际化文件
flutter gen-l10n
```

**或使用项目根目录的批量脚本：**

```bash
./scripts/pub_get_all.sh       # 所有模块获取依赖
./scripts/gen_l10n_all.sh      # 所有模块国际化生成
```

## 💡 模块特点

1. **统一入口** - 作为应用的主入口，整合所有业务功能
2. **导航框架** - 提供清晰的导航结构和页面跳转
3. **数据可视化** - 丰富的图表展示业务数据
4. **模块化集成** - 松耦合地集成各个业务模块
5. **响应式设计** - 适配不同屏幕尺寸
